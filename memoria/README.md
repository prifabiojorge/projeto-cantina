# Memoria do Sistema Cantina

Esta pasta guarda o contexto permanente da v2.0: decisões, planos, testes,
operação e incidentes. Ela pode ser versionada, mas não deve conter senhas,
API keys, banco de dados real, dumps completos ou dados sensíveis de alunos.

## Organização

- `contexto/`: regras do domínio e estado conhecido do sistema.
- `decisoes/`: decisões arquiteturais numeradas.
- `planos/`: planos de versão e execução.
- `testes/`: evidências e roteiros de validação.
- `operacao/`: guias de deploy, rede, backup e primeiro dia.
- `incidentes/`: problemas reais e respectivas correções.
- `deploy/`: anotações de Vercel, Supabase e ambientes.
